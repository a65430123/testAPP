# 開服檢查清單

每一項都要有人負責、有確認日期。狀態欄是 2026 年 11 月依專案現況填的：

- ✅ 已具備（程式或文件已經有）
- 🟡 部分具備（有基礎，還要補）
- ⬜ 尚未開始

**開服前必須全部完成的項目標示「必要」**；其餘可以排在開服後的第一個月。

## 開服的三個階段

不要一次對所有人開放。建議：

| 階段 | 對象 | 期間 | 目的 | 資料 |
|---|---|---|---|---|
| 封閉測試 | 邀請的 30–100 人 | 2 週 | 找程式問題、驗證經濟數值 | 結束後**刪檔** |
| 公開測試 | 不限，但有人數上限 | 2–4 週 | 壓力驗證、客服流程演練 | 事先公告是否刪檔；建議不刪檔但不開放儲值 |
| 正式營運 | 不限 | — | 開放儲值 | 不刪檔 |

## 2. 部署與基礎設施

| 項目 | 必要 | 狀態 | 說明 |
|---|---|---|---|
| 正式環境的 Docker Compose（伺服器、PostgreSQL、Nginx） | 必要 | ⬜ | 目前只有開發用的資料庫設定 `docker-compose.dev.yml`；規劃的架構還沒做 |
| 網域、HTTPS 憑證與自動更新 | 必要 | ⬜ | 遊戲連線要走 WSS |
| Nginx 反向代理：靜態檔、`/api`、WebSocket 升級 | 必要 | ⬜ | |
| 用戶端打包並設定 `VITE_SERVER_URL` | 必要 | 🟡 | 打包可用；正式網址待設定 |
| `NODE_ENV=production`、`JWT_SECRET`（至少 32 字元的亂數） | 必要 | ✅ | 沒設定時伺服器會拒絕啟動 |
| `CORS_ORIGIN` 設成遊戲網址（不是 `*`） | 必要 | ✅ | 設定即可 |
| `TRUST_PROXY=true`（伺服器在 Nginx 後面） | 必要 | ✅ | 設定即可；沒設的話登入頻率限制會把所有人當成同一個 IP |
| `ENABLE_GM_COMMANDS=false`、`BOSS_RESPAWN_SCALE=1` | 必要 | ✅ | 預設值就是；上線前再確認一次沒有從測試環境帶過來 |
| 資料庫每日備份，並**實際演練過還原** | 必要 | ⬜ | 沒還原過的備份不算備份 |
| 資料庫帳號只給必要的權限、不對外開放連接埠 | 必要 | ⬜ | |
| 行程當掉自動重啟 | 必要 | ⬜ | 伺服器遇到未捕捉的錯誤會存檔後結束，要靠外部機制拉起來 |
| 停機更新流程 | 必要 | 🟡 | 伺服器收到 SIGTERM 會讓所有玩家離線存檔；更新的步驟與公告流程要寫成文件並演練 |
| Redis（線上狀態、排行榜、多行程） | | ⬜ | 規劃的架構有，目前沒用到；單一行程時不需要 |
| 多行程／多台伺服器 | | ⬜ | 線上名冊、隊伍、寫入排隊目前都在單一行程的記憶體中；要擴充得先搬到 Redis |
| 日誌集中與保存期限 | | 🟡 | 可輸出 JSON 與寫檔；沒有自動清除 |
| CDN | | ⬜ | 用戶端打包後約 1.5 MB，初期可以不用 |

## 10. 開服當日

**前一天**

- [ ] 正式環境部署最終版本，跑完五組煙霧測試（用測試帳號，跑完清除）。
- [ ] 確認所有環境變數（特別是 `ENABLE_GM_COMMANDS=false`、`JWT_SECRET`、`CORS_ORIGIN`、`TRUST_PROXY`）。
- [ ] 確認備份排程有在跑，手動做一次完整備份。
- [ ] 確認警示頻道收得到測試訊息。
- [ ] 公告開服時間。

**開服前一小時**

- [ ] 值班人員就位：工程師、客服、營運負責人。
- [ ] 健康檢查正常，資料庫是乾淨的。
- [ ] 後台登入正常。

**開服後**

- [ ] 每 15 分鐘看一次：線上人數、`/api/health` 的延遲、後台的安全事件、伺服器日誌中的錯誤。
- [ ] 自己用一般帳號從註冊玩到第一個任務完成。
- [ ] 客服信箱有人看。
- [ ] 人數接近壓測上限時，依事先決定的方式處理（限制登入或公告）。

**回復計畫**

- [ ] 新版本有重大問題時：公告 → 關機（玩家自動存檔）→ 換回上一個版本的程式 → 開機。
- [ ] 資料庫 migration 沒有自動還原；新版本若有 migration，上版前先備份，回復時用備份還原（會遺失上版後的進度，要在公告中說明並補償）。
- [ ] 發現道具或星幣複製：立刻停機，用 `item_log` 找出受影響的帳號與數量，修正後再開；不要邊開著邊查。

## 目前離開服還差什麼（摘要）

依上表，**必要但尚未開始**的項目集中在五塊：

1. **部署**：正式環境的 Docker Compose、Nginx、HTTPS、備份與還原演練、自動重啟。
2. **帳號功能**：Email 綁定與忘記密碼、修改密碼、刪除帳號、註冊時的條款同意與年齡申報。
3. **內容與美術**：正式美術與音效、更多地圖與魔物。
4. **法務**：條款與隱私權政策的律師審閱、分級、營業與稅務。
5. **金流與商城**：整個尚未實作（封測與公測可以先不開）。

另外，禁言與檢舉、後台 IP 限制、正式規格的壓力測試、外部監控也都要在封測前補上。
